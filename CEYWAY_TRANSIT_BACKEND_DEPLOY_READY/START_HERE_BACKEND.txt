CEYWAY TRANSIT - BACKEND UPLOAD PACKAGE

This package is tailored to the existing Cloudflare project:
Worker: ceywaytransit1
D1 database: ceywaytransit-enquiries
Database ID: a73fe888-4373-4f26-98aa-a04e47a47889

READY TO UPLOAD (when you are prepared to activate backend):
1. Keep a backup of your existing GitHub and Cloudflare deployment.
2. Extract this ZIP and upload its CONTENTS to the root of
   the main branch of github.com/ashan87/ceywaytransit.
3. Make sure worker.ts and wrangler.jsonc are at repo root,
   and src/ files go into their matching folders.
4. Existing customized content or CSS files: compare before overwriting.
5. Cloudflare Builds will run npm run build then npx wrangler deploy.
6. After deployment, a dynamic Worker should enable Variables/Secrets.
7. Configure TURNSTILE_SITE_KEY (Text) and TURNSTILE_SECRET_KEY (Secret)
   only in Cloudflare. Rotate any secret exposed in chat/screenshots.
8. Configure Cloudflare Access, CF_ACCESS_TEAM_DOMAIN, CF_ACCESS_AUD,
   ADMIN_EMAILS before using /admin. It is denied until authenticated.
9. Verify /api/health and Forms. Test before production use.

Do NOT put Turnstile Secret Key in GitHub.
Do NOT delete the current live Worker.
Detailed setup guidance is in docs/CEYWAY_BACKEND_SETUP.md.
